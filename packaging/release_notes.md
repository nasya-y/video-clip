## Video Compilation Maker 1.0.0 for Windows (64-bit)

Turns your local videos into 30-second highlight compilations automatically — completely offline.

**Downloads**

* `VideoCompilationMaker-Setup-1.0.0.exe` — installer (recommended). Installs for the current user, no administrator rights needed, adds Start-menu and optional desktop shortcuts, includes an uninstaller.
* `VideoCompilationMaker-1.0.0-portable-win64.zip` — portable version: unzip anywhere and run `VideoCompilationMaker.exe`.

Everything needed (Python runtime, Qt, OpenCV, FFmpeg) is bundled. No internet connection, account or API key is required, and no video ever leaves your computer.

The program is not code-signed, so Windows SmartScreen may show "Windows protected your PC" the first time: click **More info → Run anyway**.

This build was produced and tested automatically on a Windows runner: the full test suite, a self-test of the packaged program and a silent install / run / uninstall of the installer all passed before publishing. See the README for usage, troubleshooting and build instructions.
